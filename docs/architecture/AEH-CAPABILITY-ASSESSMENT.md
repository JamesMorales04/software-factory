# AEH capability assessment for Software Factory

**Assessment date:** 2026-10-21. AEH authoritative GitHub `main` was `a8777a6b2bd9613d1e1af1bd0013b517fffab0bc`. The broad audit used clean local snapshot `2a996277a0ba5eb06a82b3c3e7472150a4931808`; a delta inspection of current main found additional planner WorkGraph correction (`src/agents/plannerWorkGraphCorrection.ts`) and local-only delivery (`src/delivery/local.ts`). Paths in this document are relative to the AEH repository. Code presence proves implementation shape, not live operational reliability. No AEH evaluation is a Factory certification.

Recommendations use `ADOPT`, `ADAPT`, `EVALUATE`, `DEFER`, `REJECT`. They are architecture proposals, not Product Owner approvals. Factory capability IDs refer to [the registry](../product/capabilities.yaml). Real acceptance below requires candidate-bound external execution where applicable; deterministic checks alone are insufficient for agent behavior.

Do not import AEH's controller topology, compatibility machinery, custom generic tool platform, permanently active role roster, or optional context dependencies by default. Their added processes and policy surfaces would obscure the single Core authority and raise maintenance cost without demonstrated Factory value.
